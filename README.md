# University Portal Documentation Module

A Vanilla JS recreation of the University Portal documentation flow. The current build mirrors the PDF reference as a mobile-first web prototype with alumni and staff screen states.

## Run

```bash
npm start
```

The preview server opens at the local address shown in the terminal.

## Screens

- Alumni login
- Alumni dashboard
- Alumni profile
- Document selection
- Appointment scheduling
- Request review
- Order tracking
- Staff login
- Staff dashboard
- Staff management filters
- Staff profile

## Structure

- `index.html` hosts the application shell.
- `styles.css` contains the mobile UI styling.
- `main.js` renders the PDF-matched screens and navigation.
- `server.js` provides a lightweight local preview server.
